# Brain Tumor Classifier GUI Prototype

**MS Thesis Interface Prototype**

This project preserves the Jupyter-notebook GUI prototype developed for the brain-tumor MRI identification system.

## Purpose

The interface was designed to:
- select MRI images,
- display image thumbnails,
- run model predictions,
- label images as Tumor or Healthy,
- summarize predictions in a user-facing interface.

## Relationship to Final Thesis

This notebook is an interface-development project, not an independent model-training experiment. Therefore it does **not claim a separate accuracy value**. The final trained ensemble used by the thesis application achieved **97.50% validation accuracy** and **97.17% accuracy on the separate 600-image unseen test set**.
